## What must be built

- An application that integrates the **PayPal developer platform (free sandbox)** with **any AI tool/model/platform**. PayPal integration must be *central*.
- "PayPal" includes Venmo, Braintree, Xoom, Honey, Zettle, Paidy, Hyperwallet, Simility, etc.
- Sponsor tools optional: AG Grid, APIMatic, Astropods, Bryntum, Channel3, Elastic, Kernel, Postman, Render, Zapier.
- Must be **new** or **significantly updated** during the submission period (explain the update).
- Must actually **run**. Mockups / static prototypes fail Stage One.

## Submission package (hard requirements)

1. Text description of features and functionality (English).
2. **Functional demo**: hosted URL *or* complete setup/run instructions so judges can run it. Include sandbox credentials / test accounts in README if needed.
3. **Public repo** (GitHub/GitLab/Bitbucket) with all source, assets, instructions, and an **open-source LICENSE file visible in the About section** (i.e. detected by GitHub → use MIT/Apache-2.0 at repo root).
4. **Demo video < 3 minutes**, public on **YouTube**, shows the project functioning end-to-end on the target device. No third-party trademarks / copyrighted music without permission.
5. Judges *may* judge from video + text only. The video is the product.

## Judging

**Stage One (pass/fail):** fits the theme + reasonably applies the PayPal APIs/SDKs.

**Stage Two, five equally weighted criteria (verbatim):**

1. **Technological Implementation**: "How thoroughly and skillfully does the project use PayPal Developer Platform and AI tool(s)? Does the project reflect genuine effort and a working, non-trivial implementation?"
2. **Design**: "Does the project deliver a complete, coherent product experience — not just a technical proof of concept?"
3. **Potential Impact**: "Does the project make a credible, specific case for solving a real problem for a real audience — and does the solution actually address that problem based on what's demonstrated?"
4. **Innovation/Idea**: "How creative and novel is the concept and does the project differ from existing concepts?"
5. **Presentation**: "Does the video clearly demonstrate the project working end-to-end? Does the pitch communicate what problem is solved, who it's for, and why it matters? Is the overall presentation easy to follow?"

Tie-break: criterion 1 first, then 2, 3, 4, 5. Judging may use "automated AI-driven analysis" → README and description must be machine-readable and explicit about PayPal features used.

## PayPal's own inspiration list (resources page)

- **AI Agents or Automation**: agents that *transact*, not just recommend; agent shops & checks out; scheduling assistant pays contractors when job marked complete; two agents negotiate and settle (A2A commerce).
- **Money Movement**: send by phone number; freelancer cross-client payments dashboard; gig payouts the moment a task is approved; split a dinner bill from a receipt; split a donation across causes.
- **Business Solutions**: multi-currency freelancer invoicing; creator tipping/membership; marketplace split between platform and sellers; POS add-on.
- **Consumer Experiences**: auto-categorizing budget app; request money inside chat; simpler checkout for students/families/seniors.
- **Social Impact**: accessible donation platform; microloans / fundraising for underbanked; nonprofit recurring payouts to field partners; neighbors pooling money for a solar co-op or cleanup fund.

Anything literally on this list is an "obvious" idea and will have many near-duplicates. Use it as the judges' mental model, not as the idea.
