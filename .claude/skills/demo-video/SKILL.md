# Demo video for Devpost judges

Hard rules from the official rules: < 3:00, public on YouTube, shows the project functioning on the device it was built for, no third-party trademarks or copyrighted music. Judges may grade from the video alone.

Structure (target 2:40): hook with a real-world shot and a number (0–15 s) → who/why now (15–30 s) → end-to-end demo with money visibly moving in sandbox and AI reasoning on screen (30 s–1:50) → 20 s architecture slide naming the PayPal APIs → impact and vision (2:15–2:35) → name + repo (2:40).

When asked to write the script, produce a two-column table (time, on screen | voice-over) in English, then list the exact clicks to record so nothing has to be improvised. When asked to review a cut, check: length, money movement visible, AI decision visible, problem/who/why spoken, no secrets on screen, every 10 s has a visual change.

Use `docs/plan/demo-video-script.md` as the template.
